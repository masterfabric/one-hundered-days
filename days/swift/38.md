# Day 38: Lists & Navigation - TabView & Split Views

## 📝 Today's Tasks

1.  **Build a `TabView`:** Create tabs with the modern `Tab` API and SF Symbol labels.
2.  **Adopt the Prominent Tab Role:** Use the `.prominent` tab role for a trailing-separated tab (iOS 26).
3.  **Use `NavigationSplitView`:** Build a sidebar/detail layout for iPad.
4.  **Combine Tabs with Stacks:** Give each tab its own `NavigationStack`.

## 📖 Task Explanations

Top-level navigation usually means tabs or a split view. `TabView` with the modern `Tab` API organizes major sections, and iOS 26 adds a `.prominent` tab role for trailing-separated tabs (similar to how search is presented). `NavigationSplitView` provides the sidebar-plus-detail layout that feels right on iPad and Mac, adapting to a stack on compact widths. A common structure gives each tab its own `NavigationStack` so navigation state is preserved per tab. Choosing the right top-level container shapes the whole app's information architecture.

## 💡 What You'll Gain

You will structure top-level app navigation with tabs and split views, adapting the layout across iPhone and iPad.

## 📚 Dictionary for Developers

*   **`TabView`:** A container presenting mutually exclusive top-level sections.
*   **Prominent Tab Role:** An iOS 26 role for a visually separated trailing tab.
*   **`NavigationSplitView`:** A multi-column sidebar/detail navigation container.
*   **Information Architecture:** How an app's content and navigation are organized.

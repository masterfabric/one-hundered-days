# Day 49: Networking (I) - AsyncImage & Remote Media

## 📝 Today's Tasks

1.  **Load Remote Images:** Display network images with `AsyncImage`.
2.  **Show Placeholders:** Provide loading and error phases.
3.  **Leverage HTTP Caching:** Rely on `AsyncImage`'s default HTTP cache support (requires iOS 26+).
4.  **Size & Clip Images:** Use `.resizable`, `.scaledToFill`, and `.clipShape`.

## 📖 Task Explanations

`AsyncImage(url:)` fetches and displays a remote image with no `URLSession` code of your own. Reach for it before adding a caching library — for lists, avatars, and thumbnails it is usually all you need, and it's one line.

The single-argument version shows a blank space while loading, so use the phase-based initializer instead: it hands you `.empty`, `.success(image)`, or `.failure` and lets you render each. Give the loading phase something sized like the final image — a `Color.gray.opacity(0.2)` block or a `ProgressView` — so rows don't jump as images arrive, and give the failure phase a symbol rather than nothing, or a broken image looks identical to a slow one.

Caching is handled for you (requires iOS 26+): `AsyncImage` honours standard HTTP cache headers by default, so repeat loads come from the cache rather than the network. That removes the main reason people used to reach for a third-party image library on day one. If your server sends no cache headers, that's a backend fix, not a client one.

Finally, size it correctly. `.resizable()` must come first, then a content mode: `.scaledToFit` shows the whole image inside the frame, `.scaledToFill` covers the frame and crops. Note that `scaledToFill` overflows its bounds unless you add `.clipped()` or `.clipShape(...)` — that pair of modifiers is what produces a properly cropped circular avatar rather than one that spills over its neighbours.

## 📚 Dictionary for Developers

*   **`AsyncImage`:** A view that asynchronously loads and displays a remote image.
*   **Placeholder:** Content shown while an image is loading.
*   **HTTP Caching:** Reusing responses per server cache headers to avoid refetching.
*   **Content Mode:** How an image scales to fit or fill its frame.
*   **Image Phase:** The loading state `AsyncImage` reports: empty, success, or failure.

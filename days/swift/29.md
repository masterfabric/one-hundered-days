# Day 29: Layout & Composition - Alignment Guides

## 📝 Today's Tasks

1.  **Align Across Stacks:** Use alignment to line up children on a shared edge.
2.  **Use Custom Alignment Guides:** Define an alignment guide to align disparate views.
3.  **Overlay & Background Alignment:** Position overlays/backgrounds with `alignment:`.
4.  **Debug Layout:** Use `.border` and the view-hierarchy debugger to inspect sizing.

## 📖 Task Explanations

Alignment is subtler than it first appears. Beyond a stack's basic alignment, SwiftUI lets you define custom alignment guides so views in different containers line up on a shared reference — for example, aligning a label's baseline with an icon elsewhere. Overlays and backgrounds accept an `alignment:` to position layered content. When layouts misbehave, temporary `.border` modifiers and Xcode's view-hierarchy debugger reveal the actual frames each view received. Mastering alignment gives you pixel-accurate control without resorting to hard-coded offsets.

## 💡 What You'll Gain

You will achieve precise alignment across your UI using guides and layered positioning, and debug layout issues methodically.

## 📚 Dictionary for Developers

*   **Alignment Guide:** A customizable reference SwiftUI uses to align views.
*   **Overlay/Background:** Layers drawn in front of or behind a view with their own alignment.
*   **Baseline:** The line text sits on, usable as an alignment reference.
*   **Layout Debugging:** Techniques like `.border` to visualize view frames.

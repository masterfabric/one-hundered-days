# Day 87: Navigation & Deep Linking - URL Schemes & Universal Links

## 📝 Today's Tasks

1.  **Register a URL Scheme:** Add a custom scheme and handle incoming URLs.
2.  **Set Up Universal Links:** Associate your domain for https deep links.
3.  **Handle `onOpenURL`:** Route an incoming URL to the right screen.
4.  **Parse Link Parameters:** Decode the URL into navigation values.

## 📖 Task Explanations

Deep links let external sources open a specific place in your app. A custom URL scheme (`myapp://item/42`) is the simplest form, while universal links use real `https` URLs tied to your website domain so a web link opens the app when installed and the site otherwise — the far better user experience. You receive the incoming URL via `onOpenURL`, parse it into navigation values, and append them to your navigation path to route the user precisely. Deep linking is essential for notifications, marketing, sharing, and Handoff, making it a professional necessity rather than a nicety.

## 💡 What You'll Gain

You will handle deep links via URL schemes and universal links, routing incoming URLs to the correct screen programmatically.

## 📚 Dictionary for Developers

*   **URL Scheme:** A custom protocol (`myapp://`) that opens your app.
*   **Universal Link:** An https URL that opens your app when installed.
*   **`onOpenURL`:** A modifier delivering an incoming URL to your app.
*   **Link Routing:** Mapping a parsed URL to a navigation destination.

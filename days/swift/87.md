# Day 87: Navigation & Deep Linking - URL Schemes & Universal Links

## 📝 Today's Tasks

1.  **Register a URL Scheme:** Add a custom scheme and handle incoming URLs.
2.  **Set Up Universal Links:** Associate your domain for https deep links.
3.  **Handle `onOpenURL`:** Route an incoming URL to the right screen.
4.  **Parse Link Parameters:** Decode the URL into navigation values.

## 📖 Task Explanations

Register a custom URL scheme in the target's Info settings and your app opens on `myapp://item/42`. It's the quickest deep link to get working, which makes it good for development and internal tooling — but any app can claim any scheme, so it's neither secure nor reliable for public links.

Universal links are the real answer. They're ordinary `https://` URLs on a domain you control: you host an `apple-app-site-association` file at `/.well-known/`, add the associated-domains entitlement, and the same link opens your app when installed and your website when not. No scheme prompt, no broken link for people who don't have the app.

Handle either with `.onOpenURL { url in ... }` on your root view. Note that this fires for cold launches and while the app is already running, so the handler must work from any state — a common bug is code that assumes the app just started.

Finally, parse the URL into your route type and append it to the navigation path from Day 86. Use `URLComponents` rather than string splitting, and validate rather than trusting: an incoming URL is untrusted input from outside your app, so an unrecognised path should land somewhere sensible instead of crashing. This routing is the same infrastructure notifications, Handoff, and marketing links all rely on.

## 💡 What You'll Gain

By the end of today, you will handle deep links via URL schemes and universal links, routing incoming URLs to the correct screen programmatically.

## 📚 Dictionary for Developers

*   **URL Scheme:** A custom protocol (`myapp://`) that opens your app.
*   **Universal Link:** An https URL that opens your app when installed.
*   **`onOpenURL`:** A modifier delivering an incoming URL to your app.
*   **Link Routing:** Mapping a parsed URL to a navigation destination.
*   **AASA File:** The `apple-app-site-association` file linking your domain to your app.

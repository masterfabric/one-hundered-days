# Day 64: Advanced SwiftUI UI - Liquid Glass

## 📝 Today's Tasks

1.  **Apply `glassEffect`:** Give a custom view a Liquid Glass material with `.glassEffect()` (requires iOS 26+).
2.  **Tint & Shape Glass:** Configure the glass tint and clip shape.
3.  **Group Glass Elements:** Combine multiple glass views coherently.
4.  **Audit Standard Components:** Run the app on the latest OS and list which standard components pick up Liquid Glass for free.

## 📖 Task Explanations

Apply `.glassEffect()` to a custom view and it adopts Liquid Glass — Apple's adaptive material with refraction, reflection, and motion that responds to what's behind it. It's a one-modifier change, but treat it as a decision rather than a default: glass reads as a floating control surface, so it belongs on things that float above content, not on the content itself.

Configure it next. The modifier takes a glass value you can tint and clip to a shape, so `.glassEffect(.regular.tint(.blue), in: .capsule)` gives you a tinted capsule control. Keep the tint subtle — the material's job is to sample and refract the background, and a heavy tint throws that away.

Group related elements with a `GlassEffectContainer` so several glass views render as one coherent surface rather than a pile of separate panes stacking their effects. This matters for a toolbar or a control cluster, where individually-glassed buttons look muddy and a grouped set looks like one piece of hardware.

Finally, audit what you get for free. Run the app on the latest OS and note which standard components — toolbars, tab bars, sheets, alerts — already adopt Liquid Glass without any code from you. That list is usually longer than people expect, and it tells you where custom glass would be redundant. Since the material requires iOS 26+, gate custom uses with an availability check if your deployment target reaches further back.

## 💡 What You'll Gain

By the end of today, you will integrate custom components into the Liquid Glass material system (requires iOS 26+) with `glassEffect`, giving your UI a native, current feel.

## 📚 Dictionary for Developers

*   **Liquid Glass:** Apple's adaptive, glass-like material system (requires iOS 26+).
*   **`glassEffect`:** The composable SwiftUI modifier applying Liquid Glass.
*   **Material:** A translucent, depth-aware surface style.
*   **Glass Grouping:** Combining glass elements so they read as one surface.
*   **`GlassEffectContainer`:** A container rendering multiple glass views as one surface.

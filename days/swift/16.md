# Day 16: Swift Concurrency - async/await

## 📝 Today's Tasks

1.  **Call an `async` Function:** Mark a function `async` and call it with `await`.
2.  **Await a Network Call:** Use `try await URLSession.shared.data(from:)` for a real async request.
3.  **Sequence Async Work:** Chain multiple awaits and reason about suspension points.
4.  **Bridge from Sync:** Kick off async work from a synchronous context with a `Task`.

## 📖 Task Explanations

Mark a function `async` and call it with `await`. The keyword is part of the function's type, so callers must acknowledge the suspension the same way `throws` forces them to acknowledge failure. What `await` means is precise: the function may pause here and resume later, and while it's paused the thread is handed back for other work rather than being blocked.

Then make a real request. `try await URLSession.shared.data(from: url)` returns the data and response as a tuple — one line replacing a completion handler, a weak-self capture, and a manual thread hop. Decode it with `JSONDecoder` on the same line of execution and note that errors arrive by `throw`, so the `do`/`catch` you already know handles them.

Chain several awaits and reason about the suspension points. Sequential awaits run one after another, so two 1-second calls take 2 seconds — the code reads top-to-bottom like synchronous code but each `await` is a place where other work can interleave and where state may have changed by the time you resume. Tomorrow's `async let` is how you make those two calls overlap.

Finally, bridge from synchronous code. You can't `await` inside a non-async function, so wrap the call in `Task { }` — an unstructured unit of work you can start from anywhere, including a button action. In SwiftUI, prefer `.task { }` on a view, which does the same thing but cancels automatically when the view disappears.

## 💡 What You'll Gain

By the end of today, you will write asynchronous code that reads like synchronous code, replacing callbacks with `async`/`await` — the foundation of all modern Swift concurrency.

## 📚 Dictionary for Developers

*   **`async`:** A marker that a function can suspend and resume later.
*   **`await`:** A suspension point where a function waits for async work.
*   **Suspension Point:** A place where a task can pause without blocking a thread.
*   **`Task`:** A unit of asynchronous work you can start from sync code.
*   **Cooperative Thread Pool:** Swift's fixed-size pool that runs async work without blocking OS threads.

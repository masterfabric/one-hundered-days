# Day 5: Swift Fundamentals - Collections & Closures

## 📝 Today's Tasks

1.  **Use `Array`, `Set`, `Dictionary`:** Create and mutate each; know when order, uniqueness, or key-lookup matters.
2.  **Iterate and Transform:** Apply `map`, `filter`, and `reduce` to a collection.
3.  **Write a Closure:** Store a closure in a variable and call it; understand trailing-closure syntax.
4.  **Capture Values:** Write a closure that increments a counter declared outside it, call it twice, and print the counter to confirm the capture.
5.  **Review & Practice:** Combine Days 1–5 in a short playground: model a few values with `let`/`var` and optionals, transform them with `map`/`filter`/`reduce`, and pass a capturing closure as a callback.

## 📖 Task Explanations

Create one of each collection and let the choice express your intent. `Array` is an ordered list with duplicates allowed; `Set` is unordered with guaranteed uniqueness and near-instant membership tests; `Dictionary` maps keys to values for direct lookup. Reaching for an `Array` and then searching it linearly is the classic beginner mistake where a `Set` or `Dictionary` was the right answer.

Then transform them declaratively. `map` converts each element, `filter` keeps the ones matching a condition, and `reduce` collapses a sequence into a single value. Chain a couple together and compare the result with the equivalent hand-written `for` loop — the pipeline usually says what you meant rather than how to do it, and it composes without temporary variables.

Next, write a closure and store it in a variable: `let double = { (x: Int) in x * 2 }`. A closure is a self-contained block of functionality you can pass around like any other value. Learn the trailing-closure syntax now — `items.map { $0.name }` is the same call with the braces moved outside the parentheses — because SwiftUI's entire API is built on it.

Finally, watch a closure capture its surroundings. Declare a variable outside a closure, reference it inside, then change it and call the closure: it sees the new value, because it captured the variable itself rather than a snapshot. That behaviour is what makes closures powerful and, when the captured thing is a class instance, what makes retain cycles possible — a problem you'll meet properly on Day 15.

Close the fundamentals block with a short review. Without looking at your notes, declare a small model (a few properties, at least one optional), put several instances in an array, and produce a derived result with `map`, `filter`, and `reduce`. Then store a closure that mutates an outer counter and invoke it from a fake callback. Anything you have to look up is the gap to re-read before Day 6.

## 💡 What You'll Gain

By the end of today, you will manipulate data with the three core collections and write closures — the foundation of functional-style Swift and every SwiftUI callback you will write — and you will have reviewed Days 1–5 in one small playground.

## 📚 Dictionary for Developers

*   **Array/Set/Dictionary:** Ordered list, unique unordered set, and key-value map collection types.
*   **Higher-Order Function:** A function that takes or returns another function, like `map` or `filter`.
*   **Closure:** A self-contained block of code that can be stored, passed, and can capture context.
*   **Capture:** A closure holding onto variables from its surrounding scope.
*   **Trailing Closure:** Syntax that moves a final closure argument outside the call's parentheses.

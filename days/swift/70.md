# Day 70: Animations - Canvas & Custom Drawing

## 📝 Today's Tasks

1.  **Draw with `Canvas`:** Render custom graphics imperatively in a `Canvas`.
2.  **Use `Path` & Shapes:** Build custom shapes with `Path` and the `Shape` protocol.
3.  **Animate Drawings:** Drive drawing parameters from animatable state.
4.  **Consider `TimelineView`:** Animate over real time with `TimelineView` for effects.

## 📖 Task Explanations

For visuals beyond standard views — charts, progress rings, particle effects, custom shapes — SwiftUI provides low-level drawing. The `Shape` protocol with `Path` lets you define resolution-independent vector shapes that animate their parameters, while `Canvas` offers an immediate-mode surface for drawing many elements efficiently. Pairing these with `TimelineView` (which re-renders on a schedule) enables time-based effects like clocks or animated backgrounds. These tools fill the gap between SwiftUI's built-in views and full Metal, letting you craft bespoke visuals while staying in SwiftUI.

## 💡 What You'll Gain

You will create and animate custom vector graphics with `Shape`, `Path`, and `Canvas`, covering visuals beyond SwiftUI's built-in views.

## 📚 Dictionary for Developers

*   **`Canvas`:** An immediate-mode surface for efficient custom drawing.
*   **`Path`/`Shape`:** APIs for defining custom, animatable vector shapes.
*   **`TimelineView`:** A view that re-renders on a schedule for time-based effects.
*   **Immediate-Mode Drawing:** Drawing by issuing commands each frame rather than composing views.

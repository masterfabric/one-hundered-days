# Day 70: Animations - Canvas & Custom Drawing

## 📝 Today's Tasks

1.  **Draw with `Canvas`:** Render custom graphics imperatively in a `Canvas`.
2.  **Use `Path` & Shapes:** Build custom shapes with `Path` and the `Shape` protocol.
3.  **Animate Drawings:** Drive drawing parameters from animatable state.
4.  **Animate with `TimelineView`:** Drive a time-based effect (a clock or pulse) with `TimelineView`.

## 📖 Task Explanations

Start with `Path` and the `Shape` protocol. Conform a struct to `Shape`, implement `path(in rect:)`, and you have a resolution-independent vector shape you can fill, stroke, and use as a clip. Shapes are views, so they compose normally — and because their parameters can be animatable, a progress ring is just a shape whose trim end is driven by state.

`Canvas` covers the other case: many elements drawn at once. Instead of composing a view per element, you get a graphics context and issue drawing commands imperatively in a single pass, which is far cheaper for particle effects, charts with hundreds of points, or a custom visualisation. The tradeoff is that the contents aren't views, so they can't be tapped or made accessible individually.

Animate by driving the drawing from state. A shape's parameters interpolate if the type conforms to `Animatable` with an `animatableData` property, which is what lets a wedge sweep smoothly rather than jumping between values. This is the piece people miss when a custom shape refuses to animate.

Finally, add `TimelineView` for anything driven by time rather than by user action. It re-renders its content on a schedule — `.animation`, `.periodic(from:by:)`, or `.everyMinute` — so a clock, a pulse, or an animated background updates without you managing a timer. Between shapes, `Canvas`, and `TimelineView` you can build bespoke visuals without leaving SwiftUI for Metal.

## 📚 Dictionary for Developers

*   **`Canvas`:** An immediate-mode surface for efficient custom drawing.
*   **`Path`/`Shape`:** APIs for defining custom, animatable vector shapes.
*   **`TimelineView`:** A view that re-renders on a schedule for time-based effects.
*   **Immediate-Mode Drawing:** Drawing by issuing commands each frame rather than composing views.
*   **`Animatable`:** A protocol letting custom values interpolate during an animation.

1.  **Write a `@Test`:** Create a test function with the `@Test` macro (Swift Testing).
2.  **Assert with `#expect`:** Verify conditions with `#expect(...)`.
3.  **Require with `#require`:** Halt a test on a precondition using `try #require`.
4.  **Note XCTest Interop:** Understand Swift Testing coexists with XCTest for migration.

## 📖 Task Explanations

Swift Testing is Apple's modern testing framework, and it's what you should reach for in new code. Tests are plain functions marked `@Test`, assertions use the expressive `#expect` macro (which reports rich failure detail), and `#require` stops a test early when a precondition fails or unwraps an optional. Swift Testing interoperates with XCTest, so you can migrate a codebase incrementally. Its clean syntax and better diagnostics lower the friction of writing tests, which is the whole point — tests only help if you actually write them.

## 💡 What You'll Gain

You will write your first tests with the modern Swift Testing framework, using `#expect` and `#require` for clear, expressive checks.

## 📚 Dictionary for Developers

*   **Swift Testing:** Apple's modern test framework using macros.
*   **`@Test`:** A macro marking a function as a test.
*   **`#expect`:** A macro asserting a condition with rich failure output.
*   **`#require`:** A macro that stops the test if a condition/unwrap fails.

## 📖 Task Explanations

The Observation framework (`@Observable`) is the modern way to share reference-type state with SwiftUI, and it supersedes the older `ObservableObject`/`@Published` pattern. You simply annotate a class with `@Observable`; SwiftUI then tracks exactly which properties each view reads and re-renders only those views when only those properties change. This fine-grained tracking is both simpler to write (no `@Published` on every property) and faster at runtime than the Combine-based approach. `@Observable` classes are the natural home for view models, which you'll build on in the MVVM section.

## 💡 What You'll Gain

You will manage shared model state with the modern `@Observable` macro, gaining automatic, fine-grained, high-performance UI updates.

## 📚 Dictionary for Developers

*   **Observation:** Apple's framework for tracking changes to reference-type state.
*   **`@Observable`:** A macro making a class's properties observable by SwiftUI.
*   **Fine-Grained Tracking:** Re-rendering only views that read a changed property.
*   **Legacy `ObservableObject`:** The older Combine-based pattern that `@Observable` replaces.

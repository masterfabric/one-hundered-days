# Day 73: Testing with Swift Testing - Parameterized & Organized Tests

## 📝 Today's Tasks

1.  **Parameterize a Test:** Run one test over many inputs with `@Test(arguments:)`.
2.  **Group with Suites:** Organize related tests into a `@Suite`.
3.  **Share Setup:** Use suite initializers/state for common setup.
4.  **Tag & Filter:** Apply tags to select subsets of tests.

## 📖 Task Explanations

Swift Testing makes covering many cases elegant. Parameterized tests (`@Test(arguments:)`) run the same logic across a table of inputs, each reported separately, so you cover edge cases without copy-pasting test bodies. Suites (`@Suite`) group related tests and can hold shared setup via their initializer, and tags let you filter which tests run (say, just the fast ones). Organized, data-driven tests scale far better than dozens of near-identical functions, and they document the exact input/output pairs your code is expected to handle.

## 💡 What You'll Gain

You will cover many cases with parameterized tests and structure your suite for scale, keeping tests thorough yet maintainable.

## 📚 Dictionary for Developers

*   **Parameterized Test:** One test executed over multiple argument sets.
*   **`@Suite`:** A grouping of related tests with optional shared setup.
*   **Test Tag:** A label for selecting or filtering tests.
*   **Data-Driven Testing:** Deriving test cases from a table of inputs.

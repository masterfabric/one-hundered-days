# Day 30: Layout & Composition - Adaptive & Responsive UI

## 📝 Today's Tasks

1.  **Read the Size Class:** Adapt layout using `@Environment(\.horizontalSizeClass)`.
2.  **Use `ViewThatFits`:** Let SwiftUI pick the first layout that fits with `ViewThatFits`.
3.  **Support iPad & Orientation:** Design a layout that reflows between compact and regular widths.
4.  **Preview Multiple Devices:** Add previews for different device sizes.

## 📖 Task Explanations

A professional app adapts to iPhone, iPad, orientation, and split-screen. Size classes (`compact`/`regular`) tell you the coarse space available so you can switch between, say, a stacked and a side-by-side layout. `ViewThatFits` automatically chooses the first child layout that fits the available space — perfect for gracefully degrading a wide layout to a narrow one. Combined with adaptive grids and relative frames, these tools let one codebase feel native on every screen size. Previewing across devices catches regressions before you ever build.

## 💡 What You'll Gain

You will build responsive layouts that adapt across iPhone, iPad, and orientations from a single codebase.

## 📚 Dictionary for Developers

*   **Size Class:** A coarse measure (`compact`/`regular`) of available space.
*   **`ViewThatFits`:** A container that picks the first child layout that fits.
*   **Responsive Design:** UI that reflows to fit different screen sizes and orientations.
*   **Regular/Compact:** The two size-class values driving adaptive decisions.

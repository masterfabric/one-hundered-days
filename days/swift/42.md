# Day 42: User Input & Forms - Pickers, Toggles & Steppers

## 📝 Today's Tasks

1.  **Add a `Picker`:** Let users choose from options with different picker styles.
2.  **Use `Toggle` & `Stepper`:** Capture booleans and increment/decrement values.
3.  **Pick Dates:** Add a `DatePicker` with a range.
4.  **Choose Colors:** Add a `ColorPicker` where relevant.

## 📖 Task Explanations

A `Picker` binds a selection to state and lists its options as child views, each tagged with the value it represents. The cleanest source of options is a `CaseIterable` enum conforming to `Identifiable`, which lets you build the whole picker with a `ForEach`. Then change `.pickerStyle` between `.menu`, `.segmented`, `.wheel`, and `.navigationLink` and notice that the data never changes — only the presentation.

`Toggle` and `Stepper` cover the two simplest input shapes. A `Toggle` binds to a `Bool` and renders as a switch; a `Stepper` binds to a number and takes an `in:` range plus a `step:`, clamping the value for you so you never have to bounds-check it yourself. Both accept a label view, so you can put an icon and a description on the leading side.

`DatePicker` handles dates and times, and the two arguments that matter are `displayedComponents:` — ask for `.date`, `.hourAndMinute`, or both — and a range. Passing `in: Date()...` prevents past dates outright, which is a better user experience than validating after the fact and showing an error.

`ColorPicker` rounds out the set, binding to a `Color` and presenting the system colour panel including opacity. The wider point of today is that each of these controls binds directly to your state, so the control and your model can never drift apart, and each one looks and behaves exactly as users expect from every other app on the platform — which is why reaching for a built-in control almost always beats building your own.

## 💡 What You'll Gain

By the end of today, you will build rich input forms from SwiftUI's built-in controls, each bound directly to your state.

## 📚 Dictionary for Developers

*   **`Picker`:** A control for selecting one option from several.
*   **`Toggle`/`Stepper`:** Controls for boolean and incremental numeric input.
*   **`DatePicker`:** A native control for choosing dates and times.
*   **Picker Style:** A modifier changing a picker's presentation (menu, segmented, wheel).
*   **`.tag`:** The modifier associating a picker option view with its selection value.
*   **`ColorPicker`:** A control presenting the system color panel bound to a `Color`.

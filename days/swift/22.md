# Day 22: SwiftUI Basics - Stacks & Layout Primitives

## 📝 Today's Tasks

1.  **Arrange with `VStack`/`HStack`:** Stack views vertically and horizontally.
2.  **Overlay with `ZStack`:** Layer views back-to-front.
3.  **Control Spacing & Alignment:** Set `spacing:` and `alignment:` on stacks.
4.  **Push with `Spacer`:** Use `Spacer` and `padding` to distribute space.

## 📖 Task Explanations

Stacks are SwiftUI's fundamental layout containers. `VStack` arranges children top-to-bottom, `HStack` left-to-right, and `ZStack` layers them in depth. Each takes an alignment and spacing, and `Spacer` plus `padding` let you push content around and create breathing room. Because layout is declarative, you compose these containers to build any screen without manual frame math. SwiftUI's layout system negotiates sizes between parent and child — a model you'll deepen later — but stacks are where every layout begins.

## 💡 What You'll Gain

You will compose real screen layouts from stacks, spacers, and alignment, the building blocks of every SwiftUI interface.

## 📚 Dictionary for Developers

*   **`VStack`/`HStack`/`ZStack`:** Containers arranging children vertically, horizontally, or in depth.
*   **Alignment:** How a stack lines up its children on the cross axis.
*   **`Spacer`:** A flexible view that expands to push siblings apart.
*   **Padding:** Space added around a view's edges.

# Day 68: Animations - matchedGeometryEffect

## 📝 Today's Tasks

1.  **Pair Views by ID:** Use `matchedGeometryEffect` to link two views by a shared ID.
2.  **Build a Hero Transition:** Animate a card expanding into a detail view.
3.  **Use a Namespace:** Declare a `@Namespace` to scope the effect.
4.  **Coordinate with State:** Drive the effect from a state change.

## 📖 Task Explanations

Declare `@Namespace private var namespace` in the view that contains both sides of the effect. The namespace scopes the matching, so two views can share an ID without colliding with an unrelated pair elsewhere in your app.

Tag both views with `.matchedGeometryEffect(id: item.id, in: namespace)`. When one disappears and the other appears in the same animated state change, SwiftUI interpolates size and position between them, producing the illusion that the first morphed into the second. Nothing actually moves — two separate views are being animated to look continuous.

Build the canonical use: a grid thumbnail that expands into a full detail view. Drive it from a state property holding the selected item, put both the grid and the detail in the same view (a `ZStack` works well), and toggle between them inside `withAnimation`. Keep the two views' aspect ratios similar or the interpolation will look like a stretch rather than a zoom.

Finally, expect this one to take practice. The common failures are all structural: both views must exist across the transition, the namespace must be shared, and the IDs must match exactly. When it misbehaves, check those three before adjusting timing. The payoff in perceived quality is large — hero transitions are a signature of apps that feel expensive.

## 💡 What You'll Gain

By the end of today, you will build hero-style morph animations with `matchedGeometryEffect`, a hallmark of premium, polished iOS apps.

## 📚 Dictionary for Developers

*   **`matchedGeometryEffect`:** A modifier interpolating geometry between two matched views.
*   **`@Namespace`:** A scope tying matched-geometry pairs together.
*   **Hero Transition:** An effect where one element morphs into another across screens.
*   **Geometry Matching:** Animating size/position between two identified views.
*   **Matched Pair:** Two views sharing an ID and namespace so their geometry is interpolated.

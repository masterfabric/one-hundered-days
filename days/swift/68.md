# Day 68: Animations - matchedGeometryEffect

## 📝 Today's Tasks

1.  **Pair Views by ID:** Use `matchedGeometryEffect` to link two views by a shared ID.
2.  **Build a Hero Transition:** Animate a card expanding into a detail view.
3.  **Use a Namespace:** Declare a `@Namespace` to scope the effect.
4.  **Coordinate with State:** Drive the effect from a state change.

## 📖 Task Explanations

`matchedGeometryEffect` creates the illusion that one view morphs into another by interpolating their geometry across a state change. By tagging two views with the same ID in a shared `@Namespace`, SwiftUI smoothly animates size and position between them — the technique behind hero transitions where a thumbnail expands into a full detail screen. It feels magical to users and is a signature of polished apps. The mechanics take practice (both views must exist across the transition, scoped by the same namespace), but the payoff in perceived quality is substantial.

## 💡 What You'll Gain

You will build hero-style morph animations with `matchedGeometryEffect`, a hallmark of premium, polished iOS apps.

## 📚 Dictionary for Developers

*   **`matchedGeometryEffect`:** A modifier interpolating geometry between two matched views.
*   **`@Namespace`:** A scope tying matched-geometry pairs together.
*   **Hero Transition:** An effect where one element morphs into another across screens.
*   **Geometry Matching:** Animating size/position between two identified views.

# Day 97: Release & CI/CD - Signing, Provisioning & TestFlight

## 📝 Today's Tasks

1.  **Set Up Signing:** Create the certificate, app identifier, and provisioning profile, then sign a build.
2.  **Use Automatic Signing:** Let Xcode manage signing where possible.
3.  **Distribute via TestFlight:** Upload a build and invite testers.
4.  **Gather Beta Feedback:** Collect crash reports and tester feedback before release.

## 📖 Task Explanations

Code signing ties a build to your developer identity. Three pieces work together: a *certificate* proving who you are, an *app identifier* naming the app and its capabilities, and a *provisioning profile* combining them with a list of allowed devices. A build the system will run must carry all three consistently.

Let Xcode manage it automatically for as long as you can. Automatic signing creates and renews profiles as you add capabilities, which removes most of the pain. Understanding the pieces still matters, because the day it fails — an expired certificate, a capability that doesn't match the profile, a shared team account — the error messages only make sense if you know what's being checked.

Then upload a build and distribute it through TestFlight. Internal testers get it almost immediately; external groups go through a lightweight review first. This is also where you find out whether your archive, signing, and metadata are actually correct, which is worth learning before submission day rather than during it.

Finally, use the beta phase for what it's for. Collect crash reports in App Store Connect, read the feedback testers submit with screenshots, and watch how people who didn't build the app try to use it. Real devices, real data, and real network conditions surface things your own testing never will — which is why shipping straight to the store is a choice professionals stopped making a long time ago.

## 💡 What You'll Gain

By the end of today, you will navigate code signing and run a TestFlight beta, distributing builds to testers and gathering feedback before public release.

## 📚 Dictionary for Developers

*   **Code Signing:** Cryptographically tying a build to a developer identity.
*   **Provisioning Profile:** A file authorizing an app to run on specific devices.
*   **TestFlight:** Apple's platform for distributing beta builds to testers.
*   **Beta Feedback:** Tester reports and crashes gathered before release.
*   **Archive:** The signed, distributable build produced by Xcode for upload.

# Day 6: Types & Protocols - Structs & Properties

## 📝 Today's Tasks

1.  **Design a `struct`:** Model a real entity (e.g. `User`) with stored properties.
2.  **Add Computed Properties:** Expose derived values with a computed `var` (get-only or get/set).
3.  **Use Property Observers:** React to changes with `willSet` and `didSet`.
4.  **Understand the Memberwise Initializer:** Rely on the synthesized initializer, then write a custom one.

## 📖 Task Explanations

Structs are the default building block in Swift. Beyond simple stored properties, they support computed properties that derive a value on demand, property observers (`willSet`/`didSet`) that react to mutation, and a free memberwise initializer the compiler synthesizes for you. Because structs are value types, methods that mutate their own properties must be marked `mutating`, which makes state changes explicit and local. Designing small, focused structs with clear properties is the essence of idiomatic Swift modeling.

## 💡 What You'll Gain

You will model data with rich structs that expose derived state and react to change, using Swift's value semantics to keep that state predictable.

## 📚 Dictionary for Developers

*   **Stored Property:** A constant or variable held directly by an instance.
*   **Computed Property:** A property that runs code to produce (or set) a value rather than storing one.
*   **Property Observer:** `willSet`/`didSet` blocks that run before/after a stored property changes.
*   **Memberwise Initializer:** The initializer Swift synthesizes for a struct from its stored properties.

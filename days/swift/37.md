# Day 37: Lists & Navigation - NavigationStack

## 📝 Today's Tasks

1.  **Set Up a `NavigationStack`:** Wrap content in a `NavigationStack` with a title.
2.  **Push with `NavigationLink`:** Navigate to a detail view on tap.
3.  **Use `navigationDestination`:** Map a value type to its destination view.
4.  **Avoid `NavigationView`:** Note that `NavigationView` is deprecated in favor of `NavigationStack`.

## 📖 Task Explanations

`NavigationStack` is the modern, value-driven navigation container that replaces the deprecated `NavigationView`. You wrap your root content, add `NavigationLink`s that carry a value, and register `navigationDestination(for:)` handlers that turn each value type into a destination view. This data-driven approach decouples what you navigate to from where the link lives, which is what makes programmatic and deep-link navigation possible later. Starting with the value-based pattern now (rather than the older, view-based links) sets you up for scalable navigation.

## 💡 What You'll Gain

You will implement modern, value-driven navigation with `NavigationStack`, the foundation for programmatic routing and deep linking.

## 📚 Dictionary for Developers

*   **`NavigationStack`:** The modern container managing a stack of pushed views.
*   **`NavigationLink`:** A control that pushes a destination, optionally carrying a value.
*   **`navigationDestination`:** A modifier mapping a value type to a destination view.
*   **Deprecated `NavigationView`:** The legacy container replaced by `NavigationStack`.

### 🚀 Swift & SwiftUI Developer Roadmap: Day 1 to Day 100 (Foundational Skills to Professional Competence)

> Built on the latest stable Apple toolchain (current Xcode, current iOS SDK, Swift 6.x), featuring the **Observation** framework (`@Observable`), **Swift Concurrency** with strict data-race safety, **SwiftData**, and **Swift Testing**. Where a lesson relies on a version-specific capability, the minimum required version is stated in that day (e.g. typed throws on **Swift 6.0+**, Liquid Glass on **iOS 26+**). Deprecated patterns (`NavigationView`, `ObservableObject`/`@Published` as the default, Combine-first async) are intentionally avoided in favor of their modern replacements.

| Day | Focus Area | Content Details | Goal (From Foundation to Professional) |
| :---: | :--- | :--- | :--- |
| **1-5** | **Swift Fundamentals** | `let`/`var`, **value vs. reference types**, Optionals, core types, control flow. | Solidify the foundation of the Swift language. |
| **6-10** | **Types & Protocols** | `struct`, `class`, `enum` with associated values, **protocols**, extensions. | Model data with Swift's value-type-first design. |
| **11-15** | **Generics & Error Handling** | Generics, **protocol-oriented programming**, **typed throws**, `Result`, `guard`. | Write reusable, safe, and expressive Swift. |
| **16-20** | **Swift Concurrency** | **`async`/`await`**, `Task`, structured concurrency, **actors**, `Sendable`. | Master modern, data-race-safe concurrency. |
| **21-25** | **SwiftUI Basics** | Environment setup, **`View` protocol**, `VStack`/`HStack`/`ZStack`, modifiers, `#Preview`. | Grasp SwiftUI's declarative view tree. |
| **26-30** | **Layout & Composition** | `Spacer`, **`Grid`/`LazyVGrid`**, `ScrollView`, `GeometryReader`, safe area & alignment. | Build complex, adaptive layouts. |
| **31-35** | **State & Data Flow** | **`@State`**, `@Binding`, **Observation (`@Observable`)**, `@Bindable`, `@Environment`. | Manage UI state the modern SwiftUI way. |
| **36-40** | **Lists, Navigation & First App** | `List`/`ForEach`, **`NavigationStack`**, `navigationDestination`, build a **To-Do** MVP. | Ship your first complete SwiftUI app. |
| **41-45** | **User Input & Forms** | `TextField`, `Form`, **`@FocusState`**, **validation**, gestures. | Safely capture and validate user input. |
| **46-50** | **Networking (I)** | **`URLSession`** with `async`, **`Codable`**, `JSONDecoder` strategies, HTTP errors. | Fetch and decode data type-safely. |
| **51-55** | **Networking (II) & Architecture** | API client, **Repository Pattern**, **MVVM** with `@Observable`, dependency injection. | Separate concerns with a testable architecture. |
| **56-60** | **Persistence with SwiftData** | **`@Model`**, `ModelContainer`, **`@Query`**, relationships, migrations. | Persist data locally with SwiftData. |
| **61-65** | **Advanced SwiftUI UI** | Custom components, **`ViewModifier`**, `PreferenceKey`, `@ViewBuilder`, **Liquid Glass** (`glassEffect`). | Craft reusable, native-feeling UI. |
| **66-70** | **Animations** | Implicit/explicit animation, **transitions**, `matchedGeometryEffect`, **phase animator**, `Canvas`. | Add fluid, modern motion to the app. |
| **71-75** | **Testing with Swift Testing** | **`@Test`**, `#expect`/`#require`, **parameterized tests**, mocking via protocols. | Guarantee correctness and prevent regressions. |
| **76-80** | **UI Testing & Accessibility** | **`XCUITest`**, accessibility identifiers, **VoiceOver**, Dynamic Type. | Ship reliable, accessible interfaces. |
| **81-85** | **Performance & Concurrency in Practice** | **Instruments**, `@MainActor` isolation, data-race debugging, lazy state, memory. | Diagnose and optimize real apps. |
| **86-90** | **Navigation & Deep Linking** | Programmatic `NavigationStack` paths, **deep links**, scenes/windows, multi-column. | Handle complex navigation scenarios. |
| **91-95** | **Platform Integration** | Notifications, permissions, **App Intents/Widgets**, **Swift/Objective-C interop**, background tasks. | Access platform-specific capabilities. |
| **96-100**| **Release & CI/CD** | App Store prep, **signing/TestFlight**, **GitHub Actions/Xcode Cloud**, capstone delivery. | Understand professional deployment workflows. |

# Day 8: Types & Protocols - Enums with Associated Values

## 📝 Today's Tasks

1.  **Model State with an `enum`:** Define `enum LoadState { case idle, loading, loaded(Data), failed(Error) }`.
2.  **Attach Associated Values:** Carry payloads inside cases and extract them in a `switch`.
3.  **Add Raw Values:** Back an enum with `String` or `Int` raw values and use `init?(rawValue:)`.
4.  **Add Methods & Computed Properties:** Give an enum behavior with a computed property.

## 📖 Task Explanations

Enums in Swift are vastly more capable than integer constants. Each case can carry associated values, letting a single type express a finite set of states along with the data each state needs — the `LoadState` pattern above models an entire async lifecycle in four lines. Combined with an exhaustive `switch`, associated values make illegal states unrepresentable, which is one of Swift's superpowers. Enums can also have raw values for serialization, conform to protocols, and hold methods and computed properties, making them first-class modeling tools rather than mere flags.

## 💡 What You'll Gain

You will model finite state precisely with enums and associated values, making invalid combinations impossible to represent and forcing exhaustive handling.

## 📚 Dictionary for Developers

*   **Enum:** A type defining a fixed set of related cases.
*   **Associated Value:** Data attached to a specific enum case.
*   **Raw Value:** A constant underlying value (e.g. `String`) backing each case.
*   **Exhaustiveness:** The compiler guarantee that a `switch` handles every case.

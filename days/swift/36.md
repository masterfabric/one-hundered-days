# Day 36: Lists & Navigation - List & ForEach

## 📝 Today's Tasks

1.  **Render a `List`:** Display rows of data in a scrollable `List`.
2.  **Iterate with `ForEach`:** Build rows from a collection using `Identifiable` data.
3.  **Add Swipe & Edit Actions:** Enable `.swipeActions`, delete, and move.
4.  **Style Sections:** Group rows with `Section` and choose a list style.

## 📖 Task Explanations

Render a `List` and it brings a lot for free: scrolling, row recycling, platform styling, separators, and selection. Pass it a collection directly (`List(items) { item in ... }`) for the simple case, or write out `List { ... }` with static rows and `ForEach` blocks mixed together when the screen isn't a single uniform collection.

`ForEach` is what turns data into rows, and identity is the part that matters. Conform your model to `Identifiable` — a stable `id` property, ideally a `UUID` stored on the model rather than the array index — so SwiftUI can track which row is which across updates. Using array indices as identity is the classic bug: delete an item and every row after it appears to change, producing wrong animations and stale state.

Then add interaction. `.swipeActions(edge:)` puts custom buttons behind a swipe (with `.destructive` styling and `allowsFullSwipe:` for the drag-all-the-way gesture), while `.onDelete` and `.onMove` wire up the standard delete and reorder behaviours, the latter alongside an `EditButton`. All of them work on `ForEach`, not on `List` itself.

Finally, structure and style. `Section` groups rows under a header and footer, and `.listStyle(.plain)`, `.inset`, or `.insetGrouped` changes the whole look in one modifier — try each before writing custom row backgrounds. Since so many apps are fundamentally lists of things, `List` plus stable identity is one of the highest-leverage skills in SwiftUI.

## 💡 What You'll Gain

By the end of today, you will build performant, interactive lists with sections, swipe actions, and editing, backed by stable identity for correct updates.

## 📚 Dictionary for Developers

*   **`List`:** A container rendering rows of data efficiently.
*   **`ForEach`:** A view that builds a view per element of a collection.
*   **`Identifiable`:** A protocol giving each element a stable unique `id`.
*   **Swipe Actions:** Row actions revealed by swiping.
*   **Stable Identity:** An `id` that stays with an element across insertions, deletions, and reorders.

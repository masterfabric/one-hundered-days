# Day 36: Lists & Navigation - List & ForEach

## 📝 Today's Tasks

1.  **Render a `List`:** Display rows of data in a scrollable `List`.
2.  **Iterate with `ForEach`:** Build rows from a collection using `Identifiable` data.
3.  **Add Swipe & Edit Actions:** Enable `.swipeActions`, delete, and move.
4.  **Style Sections:** Group rows with `Section` and choose a list style.

## 📖 Task Explanations

`List` is SwiftUI's high-performance container for rows of data — it recycles rows, supports selection, swipe actions, sections, and editing out of the box. You populate it with `ForEach` over a collection, and each element must be uniquely identifiable (via `Identifiable` or an explicit `id`) so SwiftUI can track rows across updates. Swipe actions, delete, and reorder are a few modifiers away. Because so many apps are fundamentally lists of things, mastering `List` and `ForEach` — especially stable identity — is one of the highest-leverage SwiftUI skills.

## 💡 What You'll Gain

You will build performant, interactive lists with sections, swipe actions, and editing, backed by stable identity for correct updates.

## 📚 Dictionary for Developers

*   **`List`:** A container rendering rows of data efficiently.
*   **`ForEach`:** A view that builds a view per element of a collection.
*   **`Identifiable`:** A protocol giving each element a stable unique `id`.
*   **Swipe Actions:** Row actions revealed by swiping.

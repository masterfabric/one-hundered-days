# Day 61: Advanced SwiftUI UI - Custom ViewModifiers

## 📝 Today's Tasks

1.  **Write a `ViewModifier`:** Encapsulate reusable styling in a `ViewModifier`.
2.  **Expose a Convenience Method:** Add a `View` extension for ergonomic use.
3.  **Parameterize Styling:** Accept parameters to vary the modifier's effect.
4.  **Build a Style System:** Assemble a small set of reusable styles.

## 📖 Task Explanations

Repeating the same modifier chain across many views is a smell. A custom `ViewModifier` packages a reusable piece of styling (a card look, a badge, a section header) into one named unit, and a matching `View` extension gives it an ergonomic call site like `.cardStyle()`. Parameterizing the modifier lets one definition cover variations. Building a small library of such styles gives your app visual consistency and makes design changes a one-line edit rather than a find-and-replace. This is the foundation of a maintainable design system.

## 💡 What You'll Gain

You will package reusable styling into custom `ViewModifier`s, building a consistent, maintainable design system for your app.

## 📚 Dictionary for Developers

*   **`ViewModifier`:** A reusable, named package of view configuration.
*   **View Extension:** An extension adding an ergonomic method for a modifier.
*   **Design System:** A consistent, reusable set of styles and components.
*   **Parameterization:** Configuring a modifier's behavior via inputs.

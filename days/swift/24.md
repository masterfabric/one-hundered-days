# Day 24: SwiftUI Basics - SF Symbols, Color & Typography

## 📝 Today's Tasks

1.  **Use SF Symbols:** Render scalable icons with `Image(systemName:)` and symbol variants.
2.  **Apply Semantic Colors:** Use `.tint`, `Color.primary`, and asset-catalog colors for light/dark.
3.  **Style Text:** Use `.font(.title)`, `.fontWeight`, and `.textCase`.
4.  **Respect Dynamic Type:** Use text styles so type scales with the user's settings.

## 📖 Task Explanations

Apple gives you a rich, consistent visual vocabulary out of the box. SF Symbols is a library of thousands of scalable, weight-matched icons that align perfectly with text. Semantic colors (`Color.primary`, `.secondary`, tints) and asset-catalog colors adapt automatically to light and dark mode. Text styles (`.title`, `.body`, `.caption`) tie your typography to Dynamic Type, so text scales with the user's accessibility settings instead of being hard-coded. Building on these system primitives makes your app look native and remain accessible with almost no extra effort.

## 💡 What You'll Gain

You will use Apple's icon, color, and typography systems to build interfaces that adapt to dark mode and accessibility settings automatically.

## 📚 Dictionary for Developers

*   **SF Symbols:** Apple's library of scalable vector icons matched to text.
*   **Semantic Color:** A color defined by role that adapts to appearance mode.
*   **Text Style:** A named font role (`.body`, `.title`) that scales with Dynamic Type.
*   **Dynamic Type:** The system feature scaling text to the user's chosen size.

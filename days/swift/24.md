# Day 24: SwiftUI Basics - SF Symbols, Color & Typography

## 📝 Today's Tasks

1.  **Use SF Symbols:** Render scalable icons with `Image(systemName:)` and symbol variants.
2.  **Apply Semantic Colors:** Use `.tint`, `Color.primary`, and asset-catalog colors for light/dark.
3.  **Style Text:** Use `.font(.title)`, `.fontWeight`, and `.textCase`.
4.  **Respect Dynamic Type:** Use text styles so type scales with the user's settings.

## 📖 Task Explanations

SF Symbols is a library of thousands of scalable, weight-matched icons that ship with the system, and you draw one with `Image(systemName: "heart")`. Because the symbols are designed against the system fonts, they align with text automatically and inherit its weight and size. Install the SF Symbols app to browse names, and try the variants — `heart` versus `heart.fill` — plus `.symbolRenderingMode` for multicolour glyphs.

Colour comes next, and the rule is to describe *role* rather than a literal value. `Color.primary` and `.secondary` adapt to light and dark mode on their own, `.tint` sets the accent used by interactive elements, and colours defined in the asset catalog can carry separate light and dark appearances. Hard-coded values like `Color(red:green:blue:)` are the thing to avoid, because they're what break your app the moment the user switches appearance.

For typography, prefer the named text styles over point sizes: `.font(.title)`, `.font(.body)`, `.font(.caption)`. Layer `.fontWeight` and `.textCase` on top when you need emphasis or capitalisation. These styles carry the system's own typographic hierarchy, so a screen built from them reads as native without you choosing a single font size.

That choice also buys you accessibility for free. Named text styles scale with Dynamic Type, which means text grows and shrinks with the size the user picked in Settings. Turn Dynamic Type up in the Xcode preview's environment overrides and check that nothing clips or overlaps — catching this now costs nothing, while retrofitting it into a screen built on fixed sizes is painful.

## 💡 What You'll Gain

By the end of today, you will use Apple's icon, color, and typography systems to build interfaces that adapt to dark mode and accessibility settings automatically.

## 📚 Dictionary for Developers

*   **SF Symbols:** Apple's library of scalable vector icons matched to text.
*   **Semantic Color:** A color defined by role that adapts to appearance mode.
*   **Text Style:** A named font role (`.body`, `.title`) that scales with Dynamic Type.
*   **Dynamic Type:** The system feature scaling text to the user's chosen size.
*   **Symbol Variant:** An alternate form of a symbol, such as filled or slashed.
*   **Asset Catalog:** The bundle resource holding colors and images per appearance.

# Day 95: Platform Integration - Background Tasks & On-Device AI

## 📝 Today's Tasks

1.  **Schedule Background Work:** Use `BGTaskScheduler` for refresh/processing tasks.
2.  **Respect System Budgets:** Work within background execution limits.
3.  **Try Foundation Models:** Run an on-device LLM prompt with the Foundation Models framework (requires iOS 26+).
4.  **Keep AI Private & Local:** Understand on-device inference keeps data on the device.

## 📖 Task Explanations

Register background task identifiers in your Info settings, then submit a `BGAppRefreshTaskRequest` or `BGProcessingTaskRequest` when the app backgrounds. The system decides when — or whether — to run it, based on usage patterns, battery, and network. You are requesting an opportunity, not scheduling a job, which is the single most misunderstood thing about this API.

Work within the budget accordingly. You get a few seconds for a refresh task and must call `setTaskCompleted(success:)` before time runs out, or the system kills the task and trusts you less next time. Always set an `expirationHandler` that cancels cleanly, and keep the work small — fetch a little, save it, finish. Test it by triggering the debugger command that simulates a launch, since waiting for the real thing is impractical.

Then try Foundation Models (iOS 26+). Create a `LanguageModelSession` and send a prompt, and Apple's on-device model returns generated text — summaries, suggestions, classifications — with no API key, no network call, and no per-token cost. It's a small model, so treat it as a capable text utility rather than a frontier LLM.

Finally, note what "on-device" buys you: the user's data never leaves the phone, the feature works offline, and there's nothing to disclose on your privacy label about sending content to a server. The constraints are real — it needs recent hardware and the model is limited — but for summarising a note or drafting a reply, local inference is now the private and practical default.

## 💡 What You'll Gain

By the end of today, you will schedule budgeted background work and run private, on-device AI with the Foundation Models framework — modern iOS's frontier capabilities.

## 📚 Dictionary for Developers

*   **`BGTaskScheduler`:** The API for scheduling background refresh/processing.
*   **Background Budget:** The limited execution time the system grants background work.
*   **Foundation Models:** Apple's framework for on-device LLM inference (requires iOS 26+).
*   **On-Device AI:** Running AI locally so data stays private on the device.
*   **Expiration Handler:** The closure the system calls when a background task is out of time.

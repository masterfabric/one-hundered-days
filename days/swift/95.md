# Day 95: Platform Integration - Background Tasks & On-Device AI

## 📝 Today's Tasks

1.  **Schedule Background Work:** Use `BGTaskScheduler` for refresh/processing tasks.
2.  **Respect System Budgets:** Work within background execution limits.
3.  **Try Foundation Models:** Run an on-device LLM prompt with the Foundation Models framework (requires iOS 26+).
4.  **Keep AI Private & Local:** Understand on-device inference keeps data on the device.

## 📖 Task Explanations

Two frontier capabilities round out platform integration. Background tasks (`BGTaskScheduler`) let your app refresh content or do processing while not in the foreground, but the system grants limited, budgeted time, so work must be efficient and cancellable. On the AI side, iOS 26's Foundation Models framework runs Apple's on-device large language model for text generation, summarization, and smart suggestions — entirely locally, so user data never leaves the device (a privacy win, and no network dependency). Note Apple Intelligence features require recent hardware. Combining background execution with on-device AI enables genuinely modern, private, intelligent features.

## 💡 What You'll Gain

You will schedule budgeted background work and run private, on-device AI with the Foundation Models framework — modern iOS's frontier capabilities.

## 📚 Dictionary for Developers

*   **`BGTaskScheduler`:** The API for scheduling background refresh/processing.
*   **Background Budget:** The limited execution time the system grants background work.
*   **Foundation Models:** Apple's framework for on-device LLM inference (requires iOS 26+).
*   **On-Device AI:** Running AI locally so data stays private on the device.

# Day 88: Navigation & Deep Linking - Scenes, Windows & Multi-Window

## 📝 Today's Tasks

1.  **Declare Multiple Scenes:** Add a second scene alongside your `WindowGroup` and launch both.
2.  **Support Multiple Windows:** Enable multi-window on iPad/Mac.
3.  **Open Auxiliary Windows:** Use `openWindow` for a secondary window/scene.
4.  **Handle State per Scene:** Keep each scene's state independent.

## 📖 Task Explanations

Add a second scene beside your `WindowGroup` — a `Window` for a single auxiliary window, or a `WindowGroup` with a value type for document-style windows — and give it an id. On iPad and Mac you can now have more than one window of your app on screen; the scene model is what makes that possible.

Enable multi-window support in the target settings for iPad, then drag your app's icon to the side of an existing window to open a second instance. Each window gets its own view hierarchy and its own `@State`, which is exactly what users expect from two windows of the same app.

Open windows programmatically with `@Environment(\.openWindow)` and `openWindow(id: "inspector")`, passing a value for value-based groups. This is how an app offers a detached inspector, a document opened in its own window, or a companion view alongside the main one.

Finally, deal with per-scene state, which is the real design problem. `@State` is per-window and independent; anything backed by `@AppStorage`, a shared model, or SwiftData is shared across all windows and will update everywhere at once. Decide for each piece of state which behaviour you want. Even for an iPhone-only app, getting the scene model right is what makes the eventual iPad or Mac version a port rather than a rewrite.

## 💡 What You'll Gain

By the end of today, you will design multi-window-capable apps using the scene model, supporting independent windows on iPad and Mac.

## 📚 Dictionary for Developers

*   **Scene:** A container for a portion of an app's UI shown in a window.
*   **`WindowGroup`:** A scene that can present multiple equivalent windows.
*   **`openWindow`:** An action opening a new window/scene programmatically.
*   **Per-Scene State:** State kept independent for each window/scene.
*   **Window Group Value:** A value passed to `openWindow` so each window shows different content.

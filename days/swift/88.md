## 📖 Task Explanations

An app is composed of scenes, and understanding the scene model unlocks multi-window experiences on iPad and Mac. The `WindowGroup` scene can spawn multiple windows, each with independent state, and `openWindow` lets you programmatically present auxiliary windows (an inspector, a document, a companion view). Managing per-scene state so windows don't interfere is the main design challenge. While iPhone apps are usually single-window, adopting the scene model correctly future-proofs your app for larger platforms and the multitasking users increasingly expect there.

## 💡 What You'll Gain

You will design multi-window-capable apps using the scene model, supporting independent windows on iPad and Mac.

## 📚 Dictionary for Developers

*   **Scene:** A container for a portion of an app's UI shown in a window.
*   **`WindowGroup`:** A scene that can present multiple equivalent windows.
*   **`openWindow`:** An action opening a new window/scene programmatically.
*   **Per-Scene State:** State kept independent for each window/scene.

# Day 41: User Input & Forms - TextField & TextEditor

## 📝 Today's Tasks

1.  **Capture Text:** Bind a `TextField` to state and set a prompt/placeholder.
2.  **Configure the Keyboard:** Set `.keyboardType`, `.textContentType`, and `.submitLabel`.
3.  **Multi-line Input:** Use `TextEditor` or an `axis: .vertical` text field.
4.  **Handle Submission:** Respond to `.onSubmit` and return-key actions.

## 📖 Task Explanations

Text input is the heart of most forms. A `TextField` bound to state updates as the user types, and configuring its content type and keyboard (email, number pad, etc.) plus the submit label makes entry fast and correct — and enables system features like autofill. For longer input, `TextEditor` or a vertically-growing text field handles multiple lines. Handling `.onSubmit` lets you react to the return key. Getting these details right is the difference between a frustrating form and one that feels effortless.

## 💡 What You'll Gain

You will capture and configure text input properly, enabling autofill, the right keyboards, and smooth submission handling.

## 📚 Dictionary for Developers

*   **`TextField`:** A single-line text input control bound to state.
*   **`textContentType`:** A hint enabling autofill (email, password, one-time code).
*   **`TextEditor`:** A multi-line text input view.
*   **`.onSubmit`:** A modifier responding to the return/submit action.

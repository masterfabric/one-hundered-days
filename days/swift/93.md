# Day 93: Platform Integration - App Intents & Widgets

## 📝 Today's Tasks

1.  **Define an `AppIntent`:** Expose an app action to Siri, Shortcuts, and Spotlight.
2.  **Build a Widget:** Create a home-screen widget with WidgetKit and a timeline.
3.  **Add Interactivity:** Make a widget button trigger an App Intent.
4.  **Provide Entities:** Expose your data to the system via App Intents entities.

## 📖 Task Explanations

App Intents let the system invoke your app's functionality — through Siri, the Shortcuts app, Spotlight, and interactive widgets — turning features into system-wide capabilities. WidgetKit builds home-screen and Lock Screen widgets whose content is driven by a timeline of entries, and modern widgets can be interactive, running an App Intent when a button is tapped without opening the app. Exposing your data as App Intent entities makes it available to Spotlight and Siri suggestions. This integration surface is increasingly where users discover and trigger app functionality, so it's a high-value skill for a native app.

## 💡 What You'll Gain

You will expose app functionality to the system with App Intents and build interactive widgets with WidgetKit.

## 📚 Dictionary for Developers

*   **App Intent:** A defined action the system can invoke (Siri/Shortcuts/widgets).
*   **WidgetKit:** The framework for building home/Lock Screen widgets.
*   **Timeline:** The schedule of entries driving a widget's content.
*   **Entity:** App data exposed to the system via App Intents.

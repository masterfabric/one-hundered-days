# Day 99: Release & CI/CD - Continuous Delivery & Fastlane

## 📝 Today's Tasks

1.  **Automate Distribution:** Extend CI to upload builds to TestFlight automatically.
2.  **Use Fastlane:** Automate signing, building, and uploading with Fastlane lanes.
3.  **Manage Versioning:** Automate build-number bumps and changelogs.
4.  **Plan Phased Rollouts:** Release gradually and monitor before full rollout.

## 📖 Task Explanations

Extend the pipeline past "tests passed" to "the build is in testers' hands". Once CI can produce a signed archive and upload it to TestFlight, releasing stops being an afternoon of manual steps someone has to remember correctly at the end of a long week.

Fastlane is the standard tool. Its lanes script the tedious parts — `match` or `sigh` for certificates and profiles, `gym` to build and archive, `pilot` to upload to TestFlight — so a release becomes one command locally and one job in CI. Start with a `beta` lane that builds and uploads, then add a `release` lane once you trust it.

Automate versioning too. Derive the build number from the CI run number or the commit count so it always increases without anyone editing a file, and generate the changelog from commit messages or merged PR titles. Both are small automations that remove exactly the kind of error that only shows up after the upload is rejected.

Finally, plan the rollout. App Store Connect's phased release ships to a growing percentage of users over seven days, so you can watch crash rates and reviews and pause if something is wrong — which is only useful if you're actually watching. Shipping to 1% and monitoring turns a release from an event you brace for into a routine step you can undo.

## 💡 What You'll Gain

By the end of today, you will automate delivery to TestFlight and the App Store with Fastlane and phased rollouts, making releases routine and low-risk.

## 📚 Dictionary for Developers

*   **Continuous Delivery:** Automating the path from a passing build to distribution.
*   **Fastlane:** A tool automating iOS build, signing, and release steps.
*   **Lane:** A scripted sequence of Fastlane actions.
*   **Phased Rollout:** Releasing to a growing fraction of users while monitoring.
*   **Phased Release:** App Store Connect's staged rollout, pausable if metrics degrade.

# Day 96: Release & CI/CD - App Store Preparation

## 📝 Today's Tasks

1.  **Configure App Metadata:** Set bundle ID, version, build number, and icons.
2.  **Register in App Store Connect:** Create the app record and fill store information.
3.  **Complete Privacy Details:** Fill the privacy nutrition label accurately.
4.  **Target the Required SDK:** Build against the latest iOS SDK that App Store Connect currently requires for new submissions.

## 📖 Task Explanations

Settle the identity fields first. The bundle identifier is permanent — it cannot be changed once the app record exists — so pick the reverse-DNS name you'll still want in five years. Then set the version (the user-facing `1.2.0`) and build number (which must increase with every upload, even for the same version), and supply the full icon set.

Create the app record in App Store Connect and fill in the store information: name, subtitle, description, keywords, category, and screenshots for each required device size. Screenshots are what most people actually judge, so treat them as design work rather than a checkbox — the first two are visible without scrolling.

Complete the privacy nutrition label honestly. It asks what data you collect, whether it's linked to the user, and whether it's used for tracking — and it must cover your third-party SDKs too, since an analytics library collecting identifiers is your disclosure to make. Inaccuracies here are a common and easily avoided rejection.

Finally, check the SDK requirement. Apple periodically raises the minimum iOS SDK for new submissions, so confirm the current requirement in App Store Connect and build against it. None of this is glamorous, but every one of these details will otherwise come back as a rejection after a wait, and the whole point is to avoid discovering them one round trip at a time.

## 💡 What You'll Gain

By the end of today, you will prepare an app for submission — metadata, privacy labels, and the required SDK — laying correct groundwork for App Store review.

## 📚 Dictionary for Developers

*   **App Store Connect:** Apple's portal for managing and submitting apps.
*   **Bundle Identifier:** The unique reverse-DNS ID for an app.
*   **Privacy Label:** The declared summary of an app's data practices.
*   **SDK Requirement:** The rule that submissions build against the current SDK.
*   **Build Number:** The value that must increase with every upload to App Store Connect.

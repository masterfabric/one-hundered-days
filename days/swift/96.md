# Day 96: Release & CI/CD - App Store Preparation

## 📝 Today's Tasks

1.  **Configure App Metadata:** Set bundle ID, version, build number, and icons.
2.  **Register in App Store Connect:** Create the app record and fill store information.
3.  **Complete Privacy Details:** Fill the privacy nutrition label accurately.
4.  **Target the Required SDK:** Build against the latest iOS SDK that App Store Connect currently requires for new submissions.

## 📖 Task Explanations

Shipping starts with meticulous preparation. In App Store Connect you create the app record and provide metadata: a unique bundle identifier, version and build numbers, an app icon, screenshots, and a description. The privacy "nutrition label" must accurately declare what data you collect and how it's used — inaccuracies cause rejections. Critically, new submissions must be built with the latest iOS SDK that App Store Connect currently requires (Apple raises this minimum periodically). Getting these details right up front avoids the frustrating back-and-forth of review rejections and is the unglamorous groundwork every release depends on.

## 💡 What You'll Gain

You will prepare an app for submission — metadata, privacy labels, and the required SDK — laying correct groundwork for App Store review.

## 📚 Dictionary for Developers

*   **App Store Connect:** Apple's portal for managing and submitting apps.
*   **Bundle Identifier:** The unique reverse-DNS ID for an app.
*   **Privacy Label:** The declared summary of an app's data practices.
*   **SDK Requirement:** The rule that submissions build against the current SDK.

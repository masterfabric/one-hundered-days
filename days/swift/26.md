# Day 26: Layout & Composition - Grids

## 📝 Today's Tasks

1.  **Build a `LazyVGrid`:** Lay out items in columns with `GridItem` definitions.
2.  **Choose Column Behaviors:** Compare `.fixed`, `.flexible`, and `.adaptive` grid items.
3.  **Use the Static `Grid`:** Align a small table with `Grid`/`GridRow`.
4.  **Combine with `ScrollView`:** Wrap a lazy grid in a `ScrollView` for large data sets.

## 📖 Task Explanations

Build a `LazyVGrid` first. You pass it an array of `GridItem`s describing the columns, then a `ForEach` of content; the grid fills row by row, wrapping automatically. "Lazy" is the important word — cells are only created as they scroll into view, which is what keeps a gallery of hundreds of images from allocating everything up front.

The `GridItem` sizing modes are where the behaviour actually comes from. `.fixed(80)` pins a column to an exact width; `.flexible()` shares the leftover space equally between columns; `.adaptive(minimum: 80)` fits as many items per row as will fit and reflows when the width changes. Build the same grid three times, one with each mode, and resize the preview — `.adaptive` is usually what you want for a responsive gallery.

The non-lazy `Grid` with `GridRow` solves a different problem. It builds everything at once, which rules it out for long lists, but in exchange it aligns cells *across* rows like a real table — ideal for a settings pane, a comparison table, or a small dashboard where column widths should agree. Use `.gridCellColumns(_:)` when one cell should span several columns.

Finally, wrap the lazy grid in a `ScrollView`. Lazy grids have no scrolling of their own, and combining the two is what makes laziness pay off — content is built as it approaches the viewport and released as it leaves. Set `spacing` on both the grid and its items deliberately, since gaps are the difference between a gallery that reads as a grid and one that reads as noise.

## 📚 Dictionary for Developers

*   **`LazyVGrid`:** A grid that builds cells lazily as they scroll into view.
*   **`GridItem`:** A description of a column's sizing behavior.
*   **Adaptive Column:** A grid item that fits as many items per row as space allows.
*   **`Grid`/`GridRow`:** Non-lazy containers for small, precisely aligned tables.
*   **Lazy Loading:** Building views only as they approach the visible area.

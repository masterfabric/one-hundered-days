# Day 26: Layout & Composition - Grids

## 📝 Today's Tasks

1.  **Build a `LazyVGrid`:** Lay out items in columns with `GridItem` definitions.
2.  **Choose Column Behaviors:** Compare `.fixed`, `.flexible`, and `.adaptive` grid items.
3.  **Use the Static `Grid`:** Align a small table with `Grid`/`GridRow`.
4.  **Combine with `ScrollView`:** Wrap a lazy grid in a `ScrollView` for large data sets.

## 📖 Task Explanations

Grids arrange content in rows and columns. `LazyVGrid`/`LazyHGrid` are lazy — they only build cells as they scroll into view, which keeps large collections performant — and are configured with `GridItem`s that can be fixed, flexible, or adaptive in width. The non-lazy `Grid` with `GridRow` is ideal for small, aligned, table-like layouts where you want cells to line up across rows. Knowing which grid to reach for, and how column sizing behaves, lets you build everything from photo galleries to dashboards cleanly.

## 💡 What You'll Gain

You will build performant grid layouts with the right sizing behavior, from adaptive galleries to aligned tabular displays.

## 📚 Dictionary for Developers

*   **`LazyVGrid`:** A grid that builds cells lazily as they scroll into view.
*   **`GridItem`:** A description of a column's sizing behavior.
*   **Adaptive Column:** A grid item that fits as many items per row as space allows.
*   **`Grid`/`GridRow`:** Non-lazy containers for small, precisely aligned tables.

# Day 4: Swift Fundamentals - Control Flow

## 📝 Today's Tasks

1.  **Branch with `if`/`else`:** Write conditional logic driven by `Bool` expressions.
2.  **Pattern-Match with `switch`:** Use an exhaustive `switch` with value binding and `where` clauses.
3.  **Loop over Ranges & Collections:** Use `for item in collection` and range operators `..<` / `...`.
4.  **Use `if`/`switch` as Expressions:** Assign a value directly from an `if` or `switch` expression (Swift 5.9+).

## 📖 Task Explanations

Control flow lets a program make decisions and repeat work. Swift's `switch` is far more powerful than the C-style version: it must be exhaustive, it binds values, and it pattern-matches on tuples, ranges, and enum cases. Modern Swift also treats `if` and `switch` as expressions, so you can assign their result straight to a `let`, which removes a lot of temporary-variable noise. Ranges (`0..<n`, `1...n`) drive clean iteration. Together these give you readable, safe branching without the fall-through footguns of older languages.

## 💡 What You'll Gain

You will control program execution with clean, exhaustive branching and looping, and use the expression forms that make Swift code concise.

## 📚 Dictionary for Developers

*   **Exhaustive `switch`:** A switch the compiler requires to cover every possible case.
*   **Value Binding:** Capturing a matched value into a local constant inside a `case`.
*   **Range Operator:** `..<` (half-open) and `...` (closed) operators that express a sequence of values.
*   **Expression:** A construct that produces a value; since Swift 5.9, `if`/`switch` can be used this way.

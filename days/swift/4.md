# Day 4: Swift Fundamentals - Control Flow

## 📝 Today's Tasks

1.  **Branch with `if`/`else`:** Write conditional logic driven by `Bool` expressions.
2.  **Pattern-Match with `switch`:** Use an exhaustive `switch` with value binding and `where` clauses.
3.  **Loop over Ranges & Collections:** Use `for item in collection` and range operators `..<` / `...`.
4.  **Use `if`/`switch` as Expressions:** Assign a value directly from an `if` or `switch` expression (Swift 5.9+).

## 📖 Task Explanations

Start with `if`/`else`. Swift's conditions must be `Bool` expressions — there is no truthiness, so `if count` won't compile where `if count > 0` will. That strictness removes a common source of bugs, and combined with optional binding (`if let`) the humble `if` covers most branching you'll write.

Then move to `switch`, which in Swift is far more capable than the C version you may know. It must be exhaustive, so the compiler tells you when you've missed a case; it binds matched values into local constants; and it pattern-matches on tuples, ranges, and enum cases. Add a `where` clause to one case to filter further, and note there is no implicit fall-through to forget a `break` for.

Loops come next. `for item in collection` iterates any sequence, and the range operators build sequences directly: `0..<n` is half-open (excludes `n`), `1...n` is closed (includes it). Pair them with `enumerated()` when you need the index alongside the element, and use `stride(from:to:by:)` when you need a step other than one.

Finally, use `if` and `switch` as expressions, available since Swift 5.9. Instead of declaring a `var` and assigning to it in every branch, write `let label = switch state { case .idle: "Idle" ... }`. The value flows straight out of the branch, the binding can stay a `let`, and the compiler still enforces exhaustiveness — less noise and more safety at once.

## 💡 What You'll Gain

By the end of today, you will control program execution with clean, exhaustive branching and looping, and use the expression forms that make Swift code concise.

## 📚 Dictionary for Developers

*   **Exhaustive `switch`:** A switch the compiler requires to cover every possible case.
*   **Value Binding:** Capturing a matched value into a local constant inside a `case`.
*   **Range Operator:** `..<` (half-open) and `...` (closed) operators that express a sequence of values.
*   **Expression:** A construct that produces a value; since Swift 5.9, `if`/`switch` can be used this way.
*   **`where` Clause:** An extra condition attached to a `case` that must also hold for it to match.

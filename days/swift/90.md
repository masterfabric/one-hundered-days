# Day 90: Navigation & Deep Linking - Handoff, Shortcuts & Continuity

## 📝 Today's Tasks

1.  **Support Handoff:** Advertise user activities with `NSUserActivity`.
2.  **Add App Shortcuts:** Expose actions as Siri/Spotlight shortcuts (preview of App Intents).
3.  **Restore from Activity:** Continue an activity on another device or from search.
4.  **Integrate with the System:** Make key screens reachable from outside the app.

## 📖 Task Explanations

Advertise what the user is doing with `NSUserActivity`. Set an activity type, give it a title and a `userInfo` payload identifying the content, and mark it current for the screen. That single object serves three purposes at once, which is the reason to bother with it.

The first is Handoff: an eligible activity appears on the user's other devices, letting them continue on the iPad what they started on the phone. The second is Spotlight — set `isEligibleForSearch` and the activity becomes findable in system search, so your content surfaces without the user opening your app at all.

Handling the return trip reuses everything from Days 86 and 87. `.onContinueUserActivity(type)` delivers the activity, you read the identifier from `userInfo`, map it to a route, and append it to the path. It's the same routing pipeline as deep links with a different entry point, which is exactly why building that pipeline properly paid off.

Finally, expose your main actions as App Shortcuts so Siri and Spotlight can trigger them — a preview of the App Intents work on Day 93. The theme across all of this is that a modern app is reachable from outside itself: search, Siri, another device, a widget. Apps that only work when opened from the home screen feel dated in a way users notice without being able to name.

## 💡 What You'll Gain

By the end of today, you will integrate your app with Handoff, Spotlight, and shortcuts via user activities, making key screens reachable across the ecosystem.

## 📚 Dictionary for Developers

*   **Handoff:** Continuity feature to resume a task on another device.
*   **`NSUserActivity`:** An object describing a continuable/searchable user activity.
*   **App Shortcut:** An exposed action available via Siri/Spotlight.
*   **Continuity:** Apple's cross-device task continuation features.
*   **Activity Type:** The reverse-DNS identifier declaring a kind of continuable user activity.

# Day 69: Animations - Phase & Keyframe Animation

## 📝 Today's Tasks

1.  **Use `PhaseAnimator`:** Cycle a view through discrete phases automatically.
2.  **Build a Keyframe Animation:** Drive multiple properties over a timeline with `KeyframeAnimator`.
3.  **Trigger on Events:** Start phase animations from state or appearance.
4.  **Design Attention Effects:** Create looping or one-shot emphasis animations.

## 📖 Task Explanations

Beyond simple state tweens, SwiftUI offers structured multi-step animation. `PhaseAnimator` moves a view through a sequence of discrete phases (idle → emphasized → settled), applying different modifiers per phase — ideal for looping attention effects or reaction animations. `KeyframeAnimator` gives frame-by-frame control, driving several properties along independent timelines for complex, choreographed motion. These tools let you express animations that would be painful to build by hand, turning intricate motion design into declarative, readable code.

## 💡 What You'll Gain

You will choreograph complex, multi-step motion with phase and keyframe animators, expressing effects simple tweens can't.

## 📚 Dictionary for Developers

*   **`PhaseAnimator`:** An animator cycling a view through discrete phases.
*   **`KeyframeAnimator`:** An animator driving properties along keyframed timelines.
*   **Phase:** One discrete step in a multi-stage animation.
*   **Keyframe:** A defined value at a point in an animation timeline.

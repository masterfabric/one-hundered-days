# Day 86: Navigation & Deep Linking - Programmatic Navigation

## 📝 Today's Tasks

1.  **Drive a Navigation Path:** Bind a `NavigationStack` to a `path` you control.
2.  **Push & Pop in Code:** Append/remove values to navigate programmatically.
3.  **Pop to Root:** Reset the stack to its root on demand.
4.  **Persist Navigation State:** Save and restore the path across launches.

## 📖 Task Explanations

Value-driven navigation shines when you control the stack in code. Binding a `NavigationStack` to a `path` array makes navigation a piece of state you can manipulate: append a value to push, remove to pop, clear to return to root. This enables flows like "after saving, jump three screens back" or "deep-link straight to a detail" that are impossible with view-embedded links. Because the path is just data, you can also encode and persist it, restoring the user's exact place after relaunch. Programmatic navigation is the backbone of the deep-linking work ahead.

## 💡 What You'll Gain

You will control navigation as state with a bound path, enabling programmatic push/pop, pop-to-root, and restorable navigation.

## 📚 Dictionary for Developers

*   **Navigation Path:** A bound collection representing the navigation stack.
*   **Programmatic Navigation:** Driving navigation from code by mutating the path.
*   **Pop to Root:** Clearing the stack back to its first screen.
*   **State Restoration:** Saving and restoring UI/navigation state across launches.

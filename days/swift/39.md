# Day 39: Lists & Navigation - Sheets, Alerts & Dialogs

## 📝 Today's Tasks

1.  **Present a Sheet:** Show a modal with `.sheet(isPresented:)` and item-based binding.
2.  **Size a Sheet:** Use `.presentationDetents` for half/large heights.
3.  **Show Alerts:** Present an `.alert` with actions and a message.
4.  **Use Confirmation Dialogs:** Offer choices with `.confirmationDialog`, including item bindings (requires iOS 26+).

## 📖 Task Explanations

Modal presentation covers sheets, alerts, and dialogs. Sheets (`.sheet`) present a view over the current context and, with `presentationDetents`, can be resized to half- or full-height for flexible bottom-sheet experiences. Alerts convey important messages and force a choice, while confirmation dialogs present a set of actions; as of iOS 26+ both support the same item-binding pattern sheets use, so a presentation appears automatically when a bound value is set. Using item-based bindings (rather than a boolean plus a separate variable) keeps presentation state consistent and bug-free.

## 💡 What You'll Gain

You will present modal content — resizable sheets, alerts, and dialogs — using the consistent item-binding pattern that keeps presentation state correct.

## 📚 Dictionary for Developers

*   **Sheet:** A modally presented view over the current context.
*   **`presentationDetents`:** Modifier setting the allowed heights of a sheet.
*   **Alert:** A modal conveying a message and requiring a choice.
*   **Confirmation Dialog:** A modal offering a set of actions, often from the bottom.

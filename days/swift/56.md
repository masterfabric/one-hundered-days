# Day 56: Persistence with SwiftData - @Model & Container

## 📝 Today's Tasks

1.  **Define a `@Model`:** Annotate a class with `@Model` to make it persistent.
2.  **Set Up the Container:** Configure a `ModelContainer` on the app with `.modelContainer`.
3.  **Access the Context:** Read the `@Environment(\.modelContext)`.
4.  **Note the Core Data Relationship:** Understand SwiftData is the modern successor to Core Data.

## 📖 Task Explanations

SwiftData is Apple's modern persistence framework and the preferred choice for new apps over Core Data. You make a model persistent simply by annotating its class with `@Model`; a `ModelContainer` (attached to your app with `.modelContainer`) manages the underlying store, and the `ModelContext` is where you insert, delete, and save objects. The API is deeply integrated with SwiftUI, so persisted data flows into your views with minimal ceremony. Starting with SwiftData means you skip Core Data's boilerplate while getting a mature store underneath.

## 💡 What You'll Gain

You will set up local persistence with SwiftData's `@Model` and `ModelContainer`, the modern replacement for Core Data.

## 📚 Dictionary for Developers

*   **SwiftData:** Apple's modern persistence framework, successor to Core Data.
*   **`@Model`:** A macro turning a class into a persistent model.
*   **`ModelContainer`:** The object managing the underlying persistent store.
*   **`ModelContext`:** The workspace for inserting, deleting, and saving models.

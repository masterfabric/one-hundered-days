# Day 48: Networking (I) - Requests, Headers & POST

## 📝 Today's Tasks

1.  **Build a `URLRequest`:** Set the HTTP method, headers, and body.
2.  **Send JSON:** Encode a `Codable` body with `JSONEncoder` for a POST.
3.  **Add Authorization:** Attach a bearer token header.
4.  **Handle Status Codes:** Branch on 2xx/4xx/5xx and decode error payloads.

## 📖 Task Explanations

Real APIs need more than GET. A `URLRequest` lets you set the method, headers (content type, authorization), and a JSON body encoded from a `Codable` value with `JSONEncoder`. Handling status codes explicitly — success, client error, server error — and decoding structured error responses turns opaque failures into actionable ones you can show the user. Building requests carefully, including auth headers, is essential for any app that talks to an authenticated backend, which is nearly all of them.

## 💡 What You'll Gain

You will construct full HTTP requests — methods, headers, auth, and JSON bodies — and handle status codes and error payloads explicitly.

## 📚 Dictionary for Developers

*   **`URLRequest`:** A configurable request specifying method, headers, and body.
*   **`JSONEncoder`:** The object that encodes a value into JSON data.
*   **Bearer Token:** An auth credential sent in the `Authorization` header.
*   **Status Code:** The HTTP result code indicating success or failure category.

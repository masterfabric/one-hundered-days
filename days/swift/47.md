# Day 47: Networking (I) - Codable & Decoding

## 📝 Today's Tasks

1.  **Model the JSON:** Create `Codable` structs matching the API's shape.
2.  **Decode a Response:** Use `JSONDecoder().decode(_:from:)`.
3.  **Map Keys & Dates:** Set `keyDecodingStrategy` and `dateDecodingStrategy`.
4.  **Customize with CodingKeys:** Rename or nest fields via `CodingKeys`.

## 📖 Task Explanations

`Codable` is Swift's built-in serialization system. By declaring structs that mirror the JSON and conforming to `Codable`, `JSONDecoder` turns raw bytes into type-safe models automatically. Decoding strategies handle common mismatches — `convertFromSnakeCase` for key naming, `iso8601` for dates — without hand-written glue, and `CodingKeys` lets you rename or restructure fields when the API doesn't match your ideal model. Getting decoding right, including graceful handling of optional and missing fields, is where most networking bugs are won or lost.

## 💡 What You'll Gain

You will decode JSON into type-safe models with `Codable`, using strategies and `CodingKeys` to bridge any API shape cleanly.

## 📚 Dictionary for Developers

*   **`Codable`:** A protocol enabling automatic encoding/decoding of a type.
*   **`JSONDecoder`:** The object that decodes JSON data into `Decodable` values.
*   **Decoding Strategy:** Configuration for key naming, dates, and data formats.
*   **`CodingKeys`:** An enum customizing the mapping between properties and JSON keys.
